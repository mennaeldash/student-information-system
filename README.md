# Student Information System (SIS)

A responsive and multilingual Student Information System built with React.js to manage academic workflows through a clean, role-based user interface.

The system focuses on providing an organized experience for students and administrators, with support for Arabic and English, responsive layouts, academic registration flows, and integration with REST APIs.

## Features

- Role-based user interface
- Responsive design for desktop and mobile
- Arabic and English language support
- RTL / LTR layout switching
- Student dashboard
- Course registration flow
- Academic calendar
- Course information and status display
- Reusable React components
- REST API integration
- API requests using Axios
- Form handling and validation
- Notifications and user feedback
- PDF generation and export functionality
- Excel file support
- Responsive navigation and layouts

## Responsive Design

The application was designed to provide a consistent user experience across different screen sizes.

Special attention was given to:

- Mobile-friendly layouts
- Responsive dashboards
- Flexible cards and containers
- Vertical scrolling without horizontal overflow
- Responsive academic calendar
- Adaptive navigation components

## Multilingual Support

The system supports both Arabic and English using `i18next`.

It dynamically switches between:

- RTL layout for Arabic
- LTR layout for English

This includes translated interface elements, calendar labels, navigation items, and page content.

## API Integration

The application communicates with backend services through REST APIs using Axios.

The frontend handles:

- Fetching dynamic data
- Authentication-related requests
- Course and registration data
- Error handling
- Loading states
- API fallback handling when required

## UI / UX

The project focuses on:

- Clean and organized interfaces
- Reusable components
- Consistent spacing and typography
- Responsive layouts
- User-friendly registration flows
- Clear academic information presentation

## Project Purpose

This project was developed to demonstrate the implementation of a real-world educational management interface using modern frontend technologies, responsive design principles, multilingual support, and REST API integration.
